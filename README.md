# Penrose Diagrams Exposition

Presentation prepared for Anvesha exploring the role of Penrose diagrams in representing the causal structure of spacetime within general relativity.

Topics covered:
1. conformal compactification
2. spacetime geometry
3. causal relationships
4. event horizons
5. black hole and cosmological spacetimes

The exposition focused on how Penrose diagrams provide a compact and intuitive framework for visualizing infinite regions of spacetime and understanding relativistic phenomena.
